# ESP32 Cognitive Rehabilitation Robot Car

A custom ESP32-based robotic platform developed for cognitive rehabilitation and neuro-motor training applications.

## Overview

Designed with concepts inspired by rehabilitation training environments.

The platform was developed to support training related to:
- Memory
- Decision-making
- Reaction time
- Cognitive response

Patients interact with the system by observing visual instructions or directional signs and responding within a limited decision time.

## Features

- ESP32-based embedded control system
- Wireless robot control
- Real-time video streaming using ESP32-CAM
- Interactive rehabilitation platform
- Compact modular robotic design
- Custom mechanical and electronics integration

## Applications

- Cognitive rehabilitation training
- Stroke patient rehabilitation
- Neuro-motor response training
- Decision-making assessment
- Interactive healthcare robotics

## System Components

- ESP32 controller
- ESP32-CAM module
- Wireless communication
- Omni-wheel robotic platform
- Embedded motor control system

## Design Goals

- Improve patient interaction
- Create engaging rehabilitation exercises
- Support flexible cognitive training scenarios
- Develop a low-cost rehabilitation robotics platform
